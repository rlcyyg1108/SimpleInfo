- `InfoBlock.build()` 的 `for (InfoItem.values())` → **`SimpleInfoConfig.orderedItems()`**（行分组/左移补位/`|` 逻辑一律不用动）。

## 六改：数值颜色拆成「正常 / 较差 / 极差」三级

用户：「信息颜色切换选项那里，现在只能切换名称和数值的颜色，我希望关闭自动后可以分别设置正常、较差、极差的颜色，
就在现在的这个选项里点击切换，也就是一个正常选项有四个可选项：名称、正常数值、较差数值、极差数值。」

### 改动
- **`InfoItem.Part`**：`NAME, VALUE, TOTAL, PERCENT` → `NAME, VALUE_GOOD, VALUE_WARN, VALUE_BAD, TOTAL, PERCENT`。
  新增 `Part.isValueLevel()` 与 `Part.keySuffix()`（name/good/warn/bad/total/percent）。
- `parts()`：普通项 4 个（名称+三级），内存项 6 个（+总分配+百分比）。
- `defaultColor`：GOOD = 绿(时间类白)、WARN = 黄 0xFFFF55、BAD = 红 0xFF5555。
- `supportsAuto`：三个数值等级都支持（时间/游戏时间除外）；PERCENT 仅内存。
- **配置 key**：`color.good` / `color.warn` / `color.bad`（替代旧 `color.value`，旧键变孤儿被忽略）；
  `auto.value`（三等级**共享同一个 BooleanValue 句柄**，`autos.put` 三次塞同一实例）/ `auto.percent`。
  ⚠️ 不能用 `color.value.good` —— 旧 `color.value` 是标量，新要当表会冲突。
- `SimpleInfoConfig.autoOf/setAuto` 改为 **null 安全**（NAME/TOTAL 没有 auto 句柄）。
- **`InfoBlock`**：删 GREEN/YELLOW/RED 常量，健康度函数改为返回 **`Level{GOOD,WARN,BAD}`**
  （`fpsLevel`/`tpsLevel`/`msptLevel`/`memoryLevel`，数据不可用返回 null → 白）；
  `color()` 自动分支用 `partOf(level)` 取该等级的自定义色 → **百分比自动也复用该三级色**。
- **`SimpleInfoConfigScreen`**：`partKey` 走 `keySuffix()`；
  新增 `applyColor(rgb)`：改三级数值色**不关自动**（否则改了看不到效果），**只有 PERCENT 手动改色才 `setAuto(false)`**；
  色板高亮不再要求「非自动」（与色号框显示一致）。
- lang：`gui.simpleinfo.part.value` 拆成 `part.good/warn/bad`（正常数值/较差数值/极差数值）。

### 行为语义（已定）
- 自动 **开**（默认）→ 数值按健康度在**自定义**的 正常/较差/极差 三色间切换。
- 自动 **关** → 数值固定用「正常数值」色。
- 阈值不变（FPS ≥60/≥30、TPS ≥19/≥15、MSPT ≤30/<50、内存 pct <90/<95）。

## 六改·补：修正「自动」的语义（用户反馈"自动好像没用了"）

上一版把「自动」做成「开=切换三级色 / 关=固定正常色」，导致机器健康时开与关都是「正常数值」色 → 自动看不出作用。
用户明确选择：**「开启之后使用默认颜色，不开则使用自定义颜色」**。改为：

- **自动开 → 用内置默认健康色**（绿 55FF55 / 黄 FFFF55 / 红 FF5555，`InfoBlock.DEFAULT_GOOD/WARN/BAD`）。
- **自动关 → 用自定义色**：数值按健康度取「正常/较差/极差」三个自定义色之一；内存百分比取它自己的固定色。
- 两者**都按健康度自动切换**，区别只在用哪套配色。
- `applyColor()` 恢复：手动改色会把该部件的「自动」关掉（= 我要用自己的颜色），改完立刻可见。
- `InfoBlock.color()` 重写：`healthDriven = 数值等级 || PERCENT`，自动开走 `defaultHealthColor(level)`，
  否则数值走 `drawColorOf(partOf(level))`、百分比走 `drawColorOf(part)`；数据不可用仍返回白。
