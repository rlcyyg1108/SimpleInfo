# Simple Info（简单信息展示）

一个 **纯客户端** 的 Minecraft HUD 模组  
在屏幕角落显示一小组可配置的实时性能 / 时间信息。

**目前支持的 Minecraft 版本**：1.20.1 forge

默认在左上角显示，示例：

```
FPS: 60 | TPS: 20.0 | MSPT: 3.10
内存占用: 1.20G / 4.00G (30%)
系统时间: 02:37 | 游戏时间: 0.9h
```

# Simple Info
A **client-only** Minecraft HUD mod.  
Displays a small set of configurable real-time performance and time information at the corner of your screen.

**Supported Minecraft Version**: 1.20.1 (Forge)

By default, it renders at the top-left corner. Example output:
```
FPS: 60 | TPS: 20.0 | MSPT: 3.10
Memory: 1.20G / 4.00G (30%)
System Time: 02:37 | Game Time: 0.9h
```
